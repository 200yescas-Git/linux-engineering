# Security

## Overview

Security es un dominio enfocado en la protección, configuración segura y administración de sistemas Linux mediante la aplicación de buenas prácticas de seguridad, hardening y controles de protección en ambientes profesionales.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con seguridad en servidores Linux, protección de servicios y reducción de riesgos en infraestructura.

---

El propósito de este dominio es desarrollar competencias relacionadas con:

- Linux Security.
- Server Hardening.
