# Hardening

## Overview

Área técnica enfocada en el fortalecimiento de sistemas Linux mediante configuraciones seguras, reducción de superficie de ataque y aplicación de buenas prácticas de seguridad.

Contiene documentación, laboratorios y rutas de aprendizaje orientadas a la protección de servidores Linux en ambientes profesionales.

---

## Purpose

Desarrollar competencias en:

- Secure Linux Configuration.
- Server Hardening.
- Security Best Practices.
- Risk Reduction.
