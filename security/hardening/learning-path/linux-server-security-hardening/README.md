# Linux Server Security Hardening

## Overview

Esta ruta de aprendizaje está orientada al fortalecimiento de servidores Linux mediante la aplicación de técnicas de seguridad, configuración segura y buenas prácticas para reducir riesgos en sistemas de infraestructura.

Su propósito es desarrollar competencias prácticas en protección de servidores Linux, aplicando controles de seguridad utilizados en ambientes profesionales.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Linux Server Hardening.
- Secure System Configuration.
- Server Protection.
- Security Best Practices.
- Infrastructure Security.
