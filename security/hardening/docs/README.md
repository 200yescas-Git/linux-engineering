# Documentation

## Overview

Este directorio contiene la documentación técnica desarrollada dentro del área **Linux Server Hardening**.

Aquí se organizan conceptos, configuraciones, procedimientos y buenas prácticas relacionadas con el fortalecimiento de sistemas Linux, protección de servicios y aplicación de controles de seguridad.

---

## Purpose

El propósito de esta documentación es:

- Documentar técnicas de hardening en Linux.
- Consolidar configuraciones seguras.
- Registrar buenas prácticas de protección de servidores.
- Servir como referencia para laboratorios de seguridad.

---

## Documentation Areas

La documentación puede incluir temas relacionados con:

- Hardening Principles.
- Secure Linux Configuration.
- SSH Security.
- User and Permission Security.
- Service Hardening.
- Firewall Configuration.
- Security Policies.
- Logging and Auditing.
- Vulnerability Reduction.
