# Rocky Linux

## Overview

Rocky Linux es un dominio enfocado en la administración, configuración y operación de sistemas basados en Rocky Linux, una distribución Enterprise Linux compatible con Red Hat Enterprise Linux (RHEL).

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con administración Linux Enterprise, servidores, seguridad y operación de infraestructura.

---

El propósito de este dominio es desarrollar competencias relacionadas con:

- Enterprise Linux Administration.
- RHEL Compatible Systems.
