# Documentation

## Overview

Este directorio contiene la documentación técnica desarrollada dentro del dominio **Rocky Linux**.

Aquí se organizan conceptos, configuraciones, procedimientos y buenas prácticas relacionadas con la administración de sistemas Enterprise Linux compatibles con el ecosistema Red Hat.

---

## Purpose

El propósito de esta documentación es:

- Organizar conocimiento técnico del dominio.
- Consolidar conceptos de administración Rocky Linux.
- Documentar configuraciones y procedimientos del sistema.
- Servir como referencia para laboratorios y futuras implementaciones.

---

## Documentation Areas

La documentación puede incluir temas relacionados con:

- Rocky Linux Fundamentals.
- Linux System Administration.
- Enterprise Linux Concepts.
- Package Management.
- Users & Groups.
- Permissions Management.
- Systemd Services.
- Networking.
- Storage Administration.
- SELinux.
- Firewalld.
- Security Hardening.
- Server Administration.
- Troubleshooting.
