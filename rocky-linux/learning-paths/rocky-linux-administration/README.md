# Rocky Linux Administration

## Overview

Esta ruta de aprendizaje está orientada a la administración de sistemas basados en **Rocky Linux**, una distribución Enterprise Linux compatible con el ecosistema Red Hat Enterprise Linux (RHEL).

Su propósito es desarrollar habilidades prácticas en instalación, configuración, administración y mantenimiento de servidores Linux Enterprise mediante herramientas y metodologías utilizadas en ambientes profesionales.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Enterprise Server Management.
