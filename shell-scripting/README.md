# Shell Scripting

## Overview

Shell Scripting es un dominio enfocado en la creación, automatización y administración de tareas mediante scripts en entornos Linux y Unix.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con automatización del sistema, administración eficiente de servidores y mejora de procesos mediante scripting.
