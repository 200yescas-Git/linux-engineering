# Shell Scripting Fundamentals

## Overview

Esta ruta de aprendizaje está orientada al desarrollo de habilidades en **Shell Scripting**, enfocándose en la creación de scripts utilizando Bash para automatizar tareas, administrar sistemas Linux y mejorar procesos operativos.

Su propósito es desarrollar una base sólida en programación de scripts para ambientes Linux, permitiendo la automatización de actividades comunes dentro de la administración de infraestructura.

---

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:
