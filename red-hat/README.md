# Red Hat

## Overview

Red Hat es un dominio enfocado en la administración, configuración y operación de sistemas empresariales basados en **Red Hat Enterprise Linux (RHEL)**.

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias profesionales en administración Linux Enterprise, automatización, seguridad y servicios utilizados en ambientes empresariales.

---

## Purpose

El propósito de este dominio es desarrollar competencias relacionadas con:

- Red Hat Enterprise Linux Administration.
- Enterprise Server Management.
- Linux System Administration.
- Automation.
- Enterprise Infrastructure.
