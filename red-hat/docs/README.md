# Documentation

## Overview

Este directorio contiene la documentación técnica desarrollada dentro del dominio **Red Hat**.

Aquí se organizan conceptos, configuraciones, procedimientos y buenas prácticas relacionadas con la administración de **Red Hat Enterprise Linux (RHEL)**, sistemas Linux Enterprise y tecnologías utilizadas en ambientes empresariales.

---

## Purpose

El propósito de esta documentación es:

- Organizar conocimiento técnico del dominio.
- Consolidar conceptos de administración Linux Enterprise.
- Documentar configuraciones y procedimientos administrativos.
- Servir como referencia para laboratorios y futuras implementaciones.

---

## Documentation Areas

La documentación puede incluir temas relacionados con:

- Red Hat Enterprise Linux Fundamentals.
- System Administration.
- Package Management.
- Systemd Services.
- Users & Groups.
- Permissions Management.
- Networking.
- Storage Administration.
- Logical Volume Management (LVM).
- SELinux.
- Firewalld.
- Bash Automation.
- Ansible Automation.
- Enterprise Linux Security.
