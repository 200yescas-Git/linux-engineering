# Red Hat Certified System Administrator (RHCSA)

## Overview

Esta ruta de aprendizaje está orientada a la preparación de la certificación **Red Hat Certified System Administrator (RHCSA)**, enfocada en el desarrollo de competencias profesionales para administrar sistemas basados en **Red Hat Enterprise Linux (RHEL)**.

Su propósito es desarrollar habilidades prácticas en administración de servidores Linux Enterprise, configuración del sistema, gestión de servicios, seguridad y resolución de problemas en ambientes empresariales.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Red Hat Enterprise Linux Administration.
- Linux System Administration.
- Server Configuration.
- System Security.
- Enterprise Infrastructure Management.
