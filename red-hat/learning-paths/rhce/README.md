# Red Hat Certified Engineer (RHCE)

## Overview

Esta ruta de aprendizaje está orientada a la preparación de la certificación **Red Hat Certified Engineer (RHCE)**, enfocada en el desarrollo de competencias avanzadas para la administración, automatización y operación de sistemas basados en **Red Hat Enterprise Linux (RHEL)**.

Su propósito es desarrollar habilidades relacionadas con automatización de infraestructura, administración avanzada de sistemas Linux Enterprise y aplicación de buenas prácticas utilizadas en ambientes profesionales.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Enterprise Linux Automation.
- Advanced System Administration.
- Configuration Management.

- Enterprise Operations.
