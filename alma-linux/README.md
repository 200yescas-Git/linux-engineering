# AlmaLinux

## Overview

AlmaLinux es un dominio enfocado en la administración, configuración y operación de sistemas basados en AlmaLinux, una distribución Enterprise Linux compatible con el ecosistema Red Hat Enterprise Linux (RHEL).

Este dominio reúne documentación técnica, laboratorios, rutas de aprendizaje y recursos orientados al desarrollo de competencias relacionadas con servidores Linux empresariales, administración de sistemas y buenas prácticas de infraestructura.
