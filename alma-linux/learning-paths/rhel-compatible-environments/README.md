# RHEL Compatible Environments

## Overview

Esta ruta de aprendizaje está orientada al estudio y administración de entornos compatibles con **Red Hat Enterprise Linux (RHEL)** utilizando distribuciones Enterprise Linux como AlmaLinux y otras plataformas compatibles.

Su propósito es desarrollar competencias prácticas relacionadas con la administración de sistemas Linux empresariales, aprovechando entornos compatibles para aprender tecnologías, herramientas y metodologías utilizadas en ambientes basados en Red Hat.

---

## Objective

El objetivo de esta ruta de aprendizaje es desarrollar competencias relacionadas con:

- Enterprise Linux Administration.
- RHEL Compatible Systems.
- Server Management.
- System Configuration.
- Linux Infrastructure Operations.
